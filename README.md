# Emotion-Recognition-System
🔍 Emotion Recognition System using VGG-19 and DASS-21
This project integrates facial emotion recognition using the VGG-19 deep learning model with psychological scoring techniques (DASS-21 and emoji-based analysis) to identify and quantify stress, anxiety, and depression levels in users. It features a user-friendly Tkinter GUI where users can upload an image, answer a DASS-21 questionnaire, and select relevant emojis. The system outputs normalized emotional scores (0 to 1 scale) to give a hybridized assessment of the user's mental state.

💡 Features:

🧠 Facial Emotion Detection using VGG-19 and FER2013 dataset

📊 Integrated DASS-21 psychological scoring

😊 Emoji-based emotion self-assessment

🔁 Normalization and hybrid scoring mechanism for final results

🖼️ Image-based emotion detection via Tkinter GUI

📉 Real-time feedback on stress, anxiety, and depression
