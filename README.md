# Emotion Recognition System using VGG-19 & DASS-21

![Emotion Recognition](https://images.unsplash.com/photo-1526379095098-d400fd0bf935?q=80&w=1200&auto=format&fit=crop)

🔍 Deep Learning based Facial Emotion Recognition with DASS-21 Hybrid Analysis

---

# 📌 Project Overview

The Emotion Recognition System is a deep learning-based application that detects human emotions from facial expressions using the VGG-19 Convolutional Neural Network (CNN) architecture.

This project combines Facial Emotion Recognition and DASS-21 psychological assessment to generate a hybrid emotional evaluation system capable of identifying:

- Stress
- Anxiety
- Depression

The system provides a smart and interactive approach for emotional state analysis through a Tkinter GUI interface.

---

# 🎯 Project Objectives

- Detect emotions from facial expressions using Deep Learning.
- Improve emotion analysis using DASS-21 psychological scoring.
- Generate normalized emotional scores between 0 to 1.
- Build a user-friendly desktop application using Tkinter.
- Create a hybrid emotional analysis system.

---

# 🧠 Problem Statement

Traditional emotion detection systems rely only on facial expressions and may not always provide accurate mental state analysis.

To improve accuracy and optimize the solution, this project combines:

- Facial Emotion Recognition
- Psychological Assessment (DASS-21)

This creates a hybrid emotion analysis system for better emotional understanding.

---

# 📂 Dataset Used

## 1️⃣ FER2013 Dataset

Initially, the model was trained using the FER2013 dataset, a widely used facial emotion recognition dataset containing thousands of grayscale facial images categorized into emotions such as:

- Happy
- Sad
- Angry
- Fear
- Neutral
- Surprise
- Disgust

The FER2013 dataset helped train the deep learning model for facial emotion classification.

---

## 2️⃣ Real-Time / Real Dataset

After training on FER2013, the system was tested using real facial images uploaded by users through the GUI interface for real-world emotion detection.

---

# 🤖 Why VGG-19?

This project uses the VGG-19 Deep Learning Model because:

- It contains 19 convolutional and fully connected layers.
- Provides high accuracy in image classification tasks.
- Extracts deep facial features effectively.
- Performs well in emotion recognition applications.
- Helps improve feature learning and model performance.

The deep architecture of VGG-19 makes it suitable for detecting subtle facial emotion patterns.
